OmniTRAF Engine Architecture & ESG Scientific Modeling

Sistem Manajemen Mobilitas Cerdas Terintegrasi ATCS SITS Surabaya — Edge AI, Sinyal Adaptif, & Formula Reduksi Emisi Karbon

⚡ 1. Pipeline Data Edge AI & Inferensi YOLOv8 dengan 60 FPS LERP (Canvas API)

OmniTRAF mengakuisisi stream video 184 node CCTV ATCS SITS Kota Surabaya via RTSP/HLS. Pemrosesan deteksi objek dilakukan di level Edge Gateway menggunakan model YOLOv8s INT8 TensorRT dan tracking multi-objek ByteTrack (Kalman Filter).

[184 CCTV RTSP SITS] ──► [Edge AI TensorRT YOLOv8] ──► [WebSocket Telemetry 300ms] ──► [Client 60 FPS LERP Canvas API]
Arsitektur 60 FPS Linear Interpolation (LERP):
Untuk menghemat bandwidth jaringan tanpa mengorbankan fluiditas tampilan, server mengirimkan pembaruan koordinat bounding box setiap 300ms. Browser menginterpolasi posisi koordinat secara linier: pos_t = pos_current + (pos_target - pos_current) × (dt × 12.0) pada loop Canvas 2D Context API 60 Hz, menghasilkan animasi kendaraan yang sangat halus tanpa lonjakan GPU (zero-bottleneck).

🚥 2. Optimasi Sinyal Adaptif (Dynamic Webster Minimum Delay Method)

Algoritma SITS menghitung alokasi Green Split secara dinamis berdasarkan derajat kejenuhan antrean ($x_i = q_i / (s_i \cdot \lambda_i)$). Mengadaptasi formula klasik Webster untuk meminimalkan keterlambatan total persimpangan:

C₀ = (1.5 × L + 5) / (1 - Y)   |   gᵢ = (C₀ - L) × (yᵢ / Y)

🌱 3. Metodologi Ilmiah Estimasi Reduksi Emisi Karbon (ESG Score)

Reduksi emisi dihitung transparan mengacu pada IPCC 2006 Guidelines for National Greenhouse Gas Inventories dan siklus uji perkotaan Dishub Surabaya. Menghitung penghematan konsumsi bahan bakar saat mesin kendaraan diam (idling) akibat antrean lampu merah:

Formula Reduksi CO₂ Harian:
ΔCO₂ (kg) = Σ (Δt_idle × N_kendaraan × SFC_idle × EF_fuel)
Δt_idle (Pengurangan Antrean) -6.4 detik / kendaraan
SFC_idle (Idle Fuel Rate) 0.28 L / jam antrean
EF_fuel (Faktor Emisi BBM) 2.31 kg CO₂ / Liter BBM
Dampak Kota Surabaya ~1.420 kg CO₂ & 580L BBM / hari
