# OmniTRAF Command Center Dashboard

Versi ini sudah menerapkan logo OmniTRAF dari gambar yang diberikan dan membersihkan background checkerboard supaya tampil lebih profesional di web.

## File
- `index.html`
- `style.css`
- `script.js`
- `assets/omnitraf-logo.png`
- `assets/omnitraf-icon.png`
- `assets/favicon.png`

## 10 Pembaruan Baru
1. Logo OmniTRAF baru diterapkan di sidebar, hero card, dan favicon.
2. Theme toggle light/dark dengan localStorage.
3. Command strip berisi search, filter, dan quick actions.
4. Search persimpangan real-time.
5. Filter kepadatan: Semua, High, Moderate, Low.
6. Interactive map density highlight.
7. AI confidence bar.
8. Signal phase control slider.
9. Incident timeline.
10. Corridor performance dan system health panel.

## 10 Perbaikan UI/UX
1. Warna diselaraskan dengan identitas logo: navy, cyan, white.
2. Logo dibuat lebih proporsional dan tidak pecah.
3. Glassmorphism diturunkan agar tidak terlalu ramai.
4. Hierarchy section lebih jelas.
5. Sidebar lebih compact dan responsif.
6. Button style dibuat konsisten.
7. Hover interaction lebih smooth.
8. Table lebih mudah dipindai dan bisa difilter.
9. Responsive mobile diperbaiki.
10. Motion menghormati `prefers-reduced-motion`.

## Cara Pakai
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Edit konten di `index.html`.
4. Edit warna/layout di `style.css`.
5. Edit interaksi di `script.js`.
